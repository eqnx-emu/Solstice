Sunshine, made for streaming to the Nintendo Switch.

Solstice is a fork of Sunshine for one setup: a Windows PC streaming to a Switch. Your games see a Switch 2 Pro Controller with gyro and HD rumble, the stream can run on a virtual display at your Switch's exact mode, and the GPU stays paced to the stream.

Download the Windows installer Compare with Sunshine

Free and open source under the GPL-3.0. Windows only. Not affiliated with LizardByte.

Press A, and the game means your A.

Upstream Sunshine shows Windows an Xbox or DualShock controller, so games prompt for the button in the wrong spot. Solstice emulates a Switch 2 Pro Controller, and Steam and your games show Nintendo prompts.

  • Works with Secure Boot on. It runs on libVIIPER over the Microsoft-signed usbip-win2 driver, so you never enable test signing.
  • Gyro and HD rumble work. Solstice forwards the gyro, accelerometer and both analog sticks to the game, and sends HD rumble back to the Switch.
  • Buttons map by position. The east button is A on your Switch and A in the game.
  • Falls back to ViGEmBus. If VIIPER is not available, Solstice uses ViGEmBus instead.

Sized and paced for the stream.

Solstice can render at the exact resolution and refresh rate the client asks for, holds the GPU to the stream's frame rate, and keeps streaming when a display blinks.

NVIDIA frame limiter, matched to the stream

While you stream, Solstice caps the NVIDIA driver's frame rate limiter to the stream's FPS. Your own setting comes back when the stream ends.

A blink of the display no longer ends the stream

Solstice keeps your display modes when a display powers off, and keeps streaming through a display that drops out for a moment.

A virtual display at the client's exact mode

Solstice can stream a virtual monitor created at the resolution and refresh rate the client asks for, using the SudoVDA driver the installer adds. Your physical monitor stays as it is. If the driver is missing, Solstice streams the physical monitor instead.

Also different.

  • Gamepad type per game

    Pick Switch, Xbox 360 or DualShock 4 for each application. On auto, the controller follows the layout chosen in the client.

  • Applications as covers

    The web UI shows your applications as a cover grid, and one click finds every missing cover.

  • Updates from Solstice

    Update checks point to Solstice releases, so the UI never offers an upstream build that would drop these features.

Solstice next to Sunshine.

Solstice follows upstream Sunshine and merges its changes. It gives up the other platforms to focus on Windows and the Switch.

Made to pair with Equinox.

Equinox is the Switch client I build alongside Solstice, and it shares the logo. It tests your connection against Solstice, recommends a bitrate and resolution, and lists your PCs with the game each one is running. Solstice still works with any Moonlight client, and Equinox with Sunshine.

Install.

Three steps on the PC, one on the Switch.

Installing over a winget-managed Sunshine? Run winget pin add --id LizardByte.Sunshine --blocking so winget upgrade does not replace Solstice.

  1. Install usbip-win2From its releases, then reboot if asked. Only needed for the Switch controller.
  2. Install SolsticeRun Sunshine-<version>-Windows-AMD64-installer.msi from the latest release. libVIIPER is included.
  3. Turn on the Switch controllerIn the web UI, open Configuration, then Input, and set Gamepad driver to viiper and Emulated gamepad type to auto.
  4. Connect from the SwitchUse Equinox, or Moonlight-Switch 1.5.3 or newer, and pick the Switch key mapping layout.
